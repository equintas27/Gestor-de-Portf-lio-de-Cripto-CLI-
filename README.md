# Gestor-de-Portf-lio-de-Cripto-CLI-
O objetivo principal é criar um programa de linha de comando que calcula o valor financeiro total da tua carteira de criptomoedas em tempo real, cruzando os dados da tua posse pessoal com as cotações atuais do mercado.

Ao invés de entrar num site ou plataforma para verificar manualmente o preço de cada moeda, o programa faz isso por ti diretamente no terminal.
